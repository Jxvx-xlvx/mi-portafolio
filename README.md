# Portafolio — Javi.dev

Portafolio personal hecho con React 19, Vite y Tailwind CSS 4.

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm run build    # build de producción en /dist
npm run lint     # oxlint
```

## Estructura

- `src/components/` — secciones de la página (Hero, Projects, Experience...)
- `src/data/` — contenido editable (proyectos, skills, experiencia, certificaciones)
